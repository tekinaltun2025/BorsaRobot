GetCorporateAccountTransactionList
Brings corporate account transactions / Firma hesap hareketlerini gösterir

The parameters that correspond to the values are; {IslemDetay1},{IslemDetay2},{IslemDetay3},{IslemDetay4},{IslemDetay5}
Invoice Collections and Corporate / Tax Payments
Gas, Water, Electricity and Telephone, GSM Bill Payments: {Invoice institution code},{Subscriber number},{Invoice number},{Invoice date},{Special reference information}
SGK Payments: {Registration number},{Accrual number “@@@" Accrual Date},{Unemployment insurance amount},{Premium amount},{Stamp Tax Amount}
For Customs Duty Payments: {Declaration Number “@@@” Serial Number},{Date},{Tax Code},{Payment amount},{Stamp duty Amount}
Other Tax Payments: {Tax Number},{Tax Type and Name},{Tax Amount},{},{}
Incoming-Outgoing Wire Transfer
Wire transactions: {Transaction description},{},{},{},{}
Check Transactions
Check transactions charged to the account: {Check City code “@@@” Check number},{Check bank code “@@@” Check account number},{Check Image Number},{Check Reference (if applicable)},{Check due date}
DBS Operations
For DBS transactions that are charged to the account: {Invoice Institution code},{Subscriber number},{Invoice number},{Invoice date},{Special reference information}
Fastpay Transactions
Fast For Fastpay Transactions Charged To the Account: {Sender Information},{Sender Phone Number},{TCKN-VKN},{},{}
Bulk Payment Transactions
In the case of mass payment transactions that have passed out of the account: {},{},{},{},{}
Foreign Exchange Buying and Selling Operations
Foreign exchange purchase and sale transactions made from the account: {Currency Codes (Buy & Sell)},{Exchange Rate},{},{},{}
Günsonu sırasında gerçekleşen işlemler için dikkat edilmesi gereken noktalar:
Error Code	Description
201005	Start date cannot be larger than end date.
201004	Start and end date range too much.
201003	Error retrieving account information.
201002	Invalid IBAN number.
201001	Account not found.
